# Power BI Dashboards

A collection of Power BI dashboards built by Jatin Kumar, covering election results, weather and air quality, retail and grocery sales, and HR attrition. Each folder has the `.pbix` file, a README and screenshots.

**Tools:** Power BI, DAX, Power Query, Data Modelling, Data Visualization

**Connect:** [linkedin.com/in/jatin-sirohi-0a28033a7](https://www.linkedin.com/in/jatin-sirohi-0a28033a7)

## Dashboards

| # | Dashboard | What it shows | Preview |
|---|-----------|---------------|---------|
| 1 | [India Election 2024 Results](election-2024) | 6-page analysis of alliance-wise seat share, state demographics and constituency drill-through | <img src="election-2024/screenshots/overview.png" width="320"> |

## How to open
Download any `.pbix` file from its folder and open it in Power BI Desktop (free).
